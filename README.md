# Vincent Hernandez Portfolio

A clean, responsive, single-page portfolio built with HTML, CSS, and JavaScript.

## Included sections
- Hero / personal introduction
- About
- Technical skills
- Selected projects
- Education and training
- Career direction
- Contact

## Before publishing
- Verify every project description against the final source code.
- Add a real GitHub profile URL if you want it displayed.
- Consider whether you want your phone number publicly visible.
- Add a verified resume PDF and a professional photo only if desired.
- Test keyboard navigation, mobile layout, and all contact links.

## Run locally
Open `index.html` directly or use VS Code Live Server.

## Deployment
Can be deployed through GitHub Pages or Vercel.
